# JKCREW 2.14.197

Coach Session Viewer cards now include a direct Daily Tricks counter. Fundamental Skills has moved out of the square counters into a slim full-width button beneath them. Both controls open the matching rider list, and the Daily counter follows the selected park.

The main and Riley app routes share this release, while keeping separate service-worker caches.
