# Official UCI ranking refresh

The app keeps two different UCI BMX Freestyle Park tables separate:

- **World rankings**: Men Elite ranking 239/group 156 and Women Elite ranking 241/group 157. These are the rolling UCI rankings and world-ranking point totals.
- **World Cup overall**: Men Elite ranking 272/group 171 and Women Elite ranking 273/group 172. These are the World Cup series standings and their own point totals.

Both use the rider's exact UCI ID. World Cup rank and points never overwrite the world-ranking values or the UCI points ledger.

The live official source check on 19 November 2026 Brisbane time returned all 359 men and 120 women in the 17 November world rankings, and all 82 men and 38 women in the 18 October World Cup standings. Lars Kindermann is world rank 13 with 2,610 points, and World Cup overall rank 10 with 1,180 points. The different publication dates are retained because the World Cup table changes with the series, rather than being assigned the weekly world-ranking date.

## Schedule and failure handling

The existing GitHub workflow checks the official sources daily, nominally at 03:23 Brisbane time. This picks up the weekly publication and catches a release posted later in UCI's time zone. GitHub scheduled jobs can start later than their nominal time. A successful check can retain the same official publication date; a source check is not a new UCI ranking release.

Each import discovers the latest published moment, then fetches every page pinned to that moment and season. Men and women must both validate before replacing the world-ranking pair. World Cup standings are also replaced as a complete pair. If that secondary source fails, the importer keeps a validated last-good World Cup pair with an explicit stale status while still publishing the freshly checked world rankings. Without a verified previous pair it reports World Cup data as unavailable.

The importer rejects unsupported sources, invalid World Cup status, missing categories and ranking-date regressions. The existing publication step rejects older world-ranking dates, concurrent SHA conflicts and failed byte verification. A failed refresh leaves the existing public data branch unchanged. The checked-in public seed is generated by the same importer, with the actual source dates and source URLs preserved.

Verification:

```sh
node --test tests/uci-rankings-import.mjs
```

`tools/update-uci-rankings.mjs --output <path>` uses the official `.org` endpoint by default. `--base https://dataride.uci.ch` selects UCI's official mirror when needed; other origins are rejected.
