# JKCREW 2.14.189 — Ten-week session planning and park fees

Coach Tools → Session Tracker now supports named 10-week training blocks.
Choose the Monday that starts week 1. The page groups weeks 1–4, 5–8 and
9–10 with blue, purple and gold accents, and marks invoice weeks 1, 4 and 8.
Monday, Tuesday and Wednesday each have an Add session action; Extra session
allows any date inside the block. Invoice labels are reminders only.

Saved rows show park locations beside rider names. The existing location and
rider dropdowns, new-location action and standalone monthly view remain
available. Existing sessions can be assigned to a block through Edit session.

An optional park entry fee is stored in AUD cents and multiplied by the saved
rider count. The editor previews the total immediately. Session, week, group
and block totals exclude archived sessions. Block totals use the complete block,
including more than 30 sessions and entries across calendar months. Filters
show matching-session subtotals while retaining the full block total.

Failed reads cannot present unknown totals as zero or reuse another block's
totals. Failed refreshes identify previously loaded data. Failed saves retain
input, stable IDs protect retries, and version checks reject conflicting edits.
Existing archive/Undo and unsaved-work update protections remain intact.

Database changes add coach-owned blocks and optional session block/fee fields.
The original save API remains available for cached clients and preserves the
new fields. Both table writes and API calls enforce ownership, Monday starts,
the 70-day window and valid fees. Changing a block cannot strand active or
archived sessions outside its dates. No invoices, payments, messages, attendance
records or scoring changes are generated by this feature.
