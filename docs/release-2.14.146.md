# Release 2.14.146 — 2v1 battles

Coaches and riders can select **2v1** or **1v2** in the existing battle builder. A rider can team up with one teammate against a solo rider, or take on a pair alone. The builder uses exactly three riders and does not automatically turn these formats into 2v2. Existing equal-team formats through 6v6v6 remain available, with 1v1 still the default.

Battle cards, invitations, selection counts and rematches use actual team sizes. Rematches preserve the original teams when initiated by the coach, either member of the pair, or the solo rider. Both teams still compete on their total training points; scores are not averaged.

The point value remains a stake **per team**, as in existing battles. For a five-point battle, the solo rider gains or loses five points; the pair shares five as three and two, using the existing deterministic whole-point remainder rule. Expiry and forfeit settlement now divide by each team's actual participant count. Draws transfer no points. No existing accounts, progress, battle records or scores were rewritten.
